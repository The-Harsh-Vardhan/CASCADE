# Candidate Applications for Blast Radius Analyzer

## Selection Criteria

The ideal application should:

- Be open source
- Have a live deployment
- Include a production-quality GitHub repository
- Have documentation
- Contain multiple user journeys
- Include authentication
- Include APIs
- Include meaningful frontend and backend relationships
- Be actively maintained
- Be realistic enough to demonstrate an evidence-backed Product Knowledge Graph
