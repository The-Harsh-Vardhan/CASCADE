📋 Recommended QA Test Checklist (Priority Order)

Please execute the following 6 manual test cases before approving this build for production:

1. 🟢 Team Public Profile Page

  • URL / Screen: https://app.documenso.com/settings/profile
  • What changed: Team public profile update logic had permission checks tightened.
  • Test Steps:
  • Log in as a Team Admin and navigate to Settings > Profile.
  • Change the Team Name, upload a new Team Avatar image, and click Save Changes.
  • Verify that changes persist without throwing 403 or 500 errors.
  • Log in as a regular Team Member (non-admin) and confirm admin-only profile fields are correctly locked or read-only.

2. 🟢 Attachment URL Validation (HTTP vs HTTPS)

  • What changed: A new URL validator (isHttpUrl) was introduced for document attachments.
  • Test Steps:
  • Open the Document Editor or Document Signing view.
  • Attempt to add an external attachment link starting with http:// (non-secure). Verify the system displays a clear validation error.
  • Attempt to add a secure https:// attachment link. Verify it is accepted successfully.

3. 🟢 Document Attachment Popovers (Upload, Edit, Delete)

  • What changed: Server-side permission logic for envelope attachments was tightened across 3 components (signing popover, document view popover, embedded editor).
  • Test Steps:
  • Open a document draft and upload a PDF attachment.
  • Edit the attachment label and then delete the attachment.
  • Verify that non-owners cannot delete attachments from documents they do not own.

4. 🟢 Document Cancellation & Deletion Permissions

  • What changed: Permission boundaries in cancel-document.ts and delete-document.ts were tightened.
  • Test Steps:
  • Attempt to cancel an active document envelope as the document owner -> verify success email and cancellation state.
  • Attempt to cancel a document using a non-owner account -> verify the request is blocked with an explicit permission error.

5. 🟢 Zapier Webhook Setup & Teardown

  • What changed: Webhook subscription and unsubscription logic (subscribe.ts / unsubscribe.ts) was updated.
  • Test Steps:
  • Go to Team Settings > Integrations > Zapier.
  • Register a test Zapier webhook -> verify successful subscription.
  • Remove the webhook -> verify teardown completes without error.

6. 🟢 Password Reset Flow

  • What changed: Password reset handler (forgot-password.ts) was modified.
  • Test Steps:
  • Go to the login screen and click Forgot Password.
  • Enter an account email and request a reset link.
  • Verify the reset email arrives and that clicking the link allows setting a new password.
